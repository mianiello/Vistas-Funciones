Qué hace el sistema

Centraliza las fichadas de entrada y salida de los relojes biométricos y las convierte en información lista para usar.

  • Audita asistencias.
  • Calcula horas trabajadas, ausencias y llegadas tarde.
  • Alimenta los dashboards y los mapas de calor.

Base de datos relacional en MySQL

empleados
Legajo, nombre, apellido y datos del personal.
registros_asistencia
Marcaciones reales: id_empleado, fecha_hora, tipo (entrada/salida).
configuracion
Reglas de negocio: horarios, tolerancias y turnos.

empleados.id ──< registros_asistencia.id_empleado

Vistas con JOIN

Una vista es una tabla virtual creada con un SELECT: no guarda datos propios, simplifica consultas complejas, aporta seguridad y facilita la lectura.

Vista 1

v_presentismo_diario

CREATE VIEW v_presentismo_diario AS
SELECT e.id AS empleado_id, e.legajo,
  CONCAT(e.nombre,' ',e.apellido) AS nombre_completo,
  r.fecha_hora AS hora_marcacion,
  r.tipo AS tipo_evento
FROM empleados e
INNER JOIN registros_asistencia r
  ON e.id = r.id_empleado
WHERE DATE(r.fecha_hora) = CURDATE();

Para qué: une cada empleado con sus fichadas de hoy. Alimenta las tarjetas Presentes/Ausentes del Dashboard sin escribir JOINs en PHP.

Vista 2

v_resumen_fichadas_completas

CREATE VIEW v_resumen_fichadas_completas AS
SELECT e.legajo,
  CONCAT(e.nombre,' ',e.apellido) AS empleado,
  DATE(r.fecha_hora) AS fecha,
  MIN(CASE WHEN r.tipo='entrada'
    THEN TIME(r.fecha_hora) END) AS hora_entrada,
  MAX(CASE WHEN r.tipo='salida'
    THEN TIME(r.fecha_hora) END) AS hora_salida
FROM empleados e
INNER JOIN registros_asistencia r
  ON e.id = r.id_empleado
GROUP BY e.id, DATE(r.fecha_hora);

Para qué: agrupa entrada y salida de cada jornada. Es la base del mapa de calor y de los reportes de liquidación.

Vista modificada y vista eliminada

Vista 3

v_empleados_activos

Creación inicial

CREATE VIEW v_empleados_activos AS
SELECT id, legajo, nombre, apellido, area
FROM empleados;

Modificación con CREATE OR REPLACE VIEW

CREATE OR REPLACE VIEW v_empleados_activos AS
SELECT id, legajo, nombre, apellido,
       area, fecha_ingreso
FROM empleados
WHERE estado = 'ACTIVO';

Para qué: oculta información sensible y muestra solo al personal habilitado. Se actualizó para sumar la fecha de ingreso y filtrar por estado.

Vista 4

v_registros_temp

Creación

CREATE VIEW v_registros_temp AS
SELECT * FROM registros_asistencia
WHERE DATE(fecha_hora) = '2026-01-01';

Eliminación con DROP VIEW

DROP VIEW v_registros_temp;

Por qué se eliminó: era una vista de auditoría temporal para las pruebas de integración del reloj biométrico. Terminada la prueba, se quitó para mantener limpio el diccionario de datos.

Tres funciones almacenadas

Procesan datos en el servidor y devuelven un único valor. Los cálculos son iguales sin importar el cliente, mejoran el rendimiento y reducen el tráfico de red.

Función 1

fn_calcular_horas_trabajadas

DETERMINISTIC · NO SQL 
CREATE FUNCTION fn_calcular_horas_trabajadas(
  p_entrada DATETIME, p_salida DATETIME)
RETURNS DECIMAL(5,2)
DETERMINISTIC NO SQL
BEGIN
 DECLARE v_minutos INT;
 IF p_entrada IS NULL OR
    p_salida IS NULL THEN
   RETURN 0.00;
 END IF;
 SET v_minutos = TIMESTAMPDIFF(
   MINUTE, p_entrada, p_salida);
 RETURN ROUND(v_minutos/60.0, 2);
END

Para qué: devuelve las horas decimales de la jornada a partir de entrada y salida.

Función 2

fn_determinar_llegada_tarde

DETERMINISTIC · NO SQL 
CREATE FUNCTION fn_determinar_llegada_tarde(
  p_hora_marcacion TIME,
  p_hora_esperada TIME)
RETURNS VARCHAR(20)
DETERMINISTIC NO SQL
BEGIN
 IF p_hora_marcacion IS NULL THEN
   RETURN 'AUSENTE';
 ELSEIF p_hora_marcacion <=
   ADDTIME(p_hora_esperada,'00:15:00')
   THEN RETURN 'A TIEMPO';
 ELSE RETURN 'LLEGADA TARDE';
 END IF;
END

Para qué: compara la marcación con la tolerancia (15 min) y clasifica el estado para las tarjetas del panel.

Función 3

fn_obtener_nombre_empleado

READS SQL DATA · DETERMINISTIC 
CREATE FUNCTION fn_obtener_nombre_empleado(
  p_empleado_id INT)
RETURNS VARCHAR(100)
READS SQL DATA DETERMINISTIC
BEGIN
 DECLARE v_nombre VARCHAR(100);
 SELECT CONCAT(nombre,' ',apellido)
   INTO v_nombre
 FROM empleados
 WHERE id = p_empleado_id;
 RETURN IFNULL(v_nombre,
   'Empleado no encontrado');
END

Para qué: devuelve el nombre completo a partir del ID y evita repetir el CONCAT en PHP.
